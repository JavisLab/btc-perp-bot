# BTC Perp Bot

비트코인 무기한 선물 자동매매를 연구하고 검증하는 비공개 프로젝트.
첫 거래소 후보는 **Hyperliquid**이며, 거래소와 전략은 아직 최종 확정하지 않았다.

## 목표

장기적으로 거래·운영 비용을 제외하고 월 **150,000원**을 남겨 구독료를 충당하는 것이 목표다.
이는 희망 목표이지 예상 수익이나 매월 수익 보장이 아니다.
첫 개발 목표는 수익 금액을 맞추는 것이 아니라, **비용을 반영한 검증에서 유효한 전략인지 확인하는 것**이다.

## 현재 상태 — 2026-09-29

- 저장소와 초기 기획 문서만 생성했다.
- 운용 원금, 허용 손실, 전략, 레버리지는 미정이다.
- 거래 프로그램, 주문 전송 기능, 상시 실행 서비스는 아직 없다.
- 지갑·API 키 연결, 입금, 실거래는 하지 않았다.

## 제안하는 진행 순서

1. 원금과 손실 허용 범위, 성과 측정 기준을 정한다.
2. BTC 가격·호가·펀딩 데이터를 수집하고 품질을 확인한다.
3. 설명 가능한 규칙 기반 전략을 비용 포함 백테스트로 검증한다.
4. 실시간 모의매매로 성과와 주문·장애 처리 가정을 점검한다.
5. 결과가 충분할 때 소액 실거래 전환 여부를 별도로 결정한다.

테스트넷은 API 기능 검증용이며, 그 수익률을 메인넷에서의 수익성 증거로 사용하지 않는다.
구독료 목표를 채우기 위해 거래 횟수나 레버리지를 자동으로 늘리지 않는다.

## 개발 방향 제안

Python을 첫 후보로 검토한다. 초기에는 BTC 단일 시장과 낮은 거래 빈도의 단순 전략부터 비교한다.
데이터 수집, 전략, 리스크 관리, 주문 실행, 성과 기록을 분리하고, 연구와 모의매매부터 구현한다.
LLM은 연구·코드·결과 해석을 돕는 용도로 두고, 주문 판단은 재현 가능한 규칙으로 시작한다.
아직 기술 스택을 확정하거나 의존성을 설치하지 않았다.

비밀키·시드 문구·개인 계좌 자료는 Git, 채팅, 로그에 남기지 않는다.
