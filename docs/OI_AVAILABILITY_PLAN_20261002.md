# 실제 파생시장 정보 · 자료 경제성 감사 계획

ETH 전이80계좌 검산 후의 다음 자료 단계. **새 전략/계좌/수익 계산 없이** 실제 미결제약정(OI)·공격적체결 자료를 더 조사할 경제적 가치가 있는지 확인한다. 이전기간의 새OOS 주장 없음.

1. Binance 공식 공개S3의 BTCUSDT/ETHUSDT `daily/metrics/` 목록을 모든 페이지 끝까지 열거한다. 평가범위2022-01-01~2026-08-31의 일별 ZIP/CHECKSUM 존재·날짜누락·크기·LastModified를 기록한다. 파일명이 있다는 것과 내부관측이 완전한 것은 구분한다.
2. 구조 샘플은 종목별 목록상 최초일/최종일 및 고정날짜2022-01-01,2022-06-23,2022-07-04,2023-11-14,2024-10-28,2025-01-29,2025-12-31,2026-01-01,2026-08-31. 기존자료 상충일을 명시적으로 포함한 품질표본이며 수익을 보고 고른 날짜가 아니다. 파일없음/체크섬불일치/형식변화도 보존한다. 데이터 전체 정상이라는 추정에 쓰지 않는다.
3. 표본 ZIP/CHECKSUM을 보존·검증하고 컬럼·UTC5분 정렬/개수/공백/중복·양수OI/금액·공격적체결 ratio의 유한성 및0을 조사한다. ratio를 실제 매수/매도수량 또는 펀딩현금흐름으로 꾸미지 않는다.
4. 현재 파일의 LastModified는 최초 실시간 가용시각이 아니다. 소급보완·개정과 집계 구간 의미, 공표 지연의 실제증거가 없으면 point-in-time 사실로 확정하지 않는다. 분명히 정의된 보수적지연/대조군 없이는 신호성과계산으로 건너뛰지 않는다.
5. 이미 검증한 1h taker buy/총량과 과거funding은 재수집하지 않는다. OI의 실재·자료범위가 확인되면 다음 작업은 전기간내부완전성/시각의미 감사와 별도 사전명세다. 자료부재/의미불명으로 새정보가 없으면 반복최적화대신 일정을 조정한다.

문서 조회 중 공식 derivatives 개발자 문서는 HTTP202/빈 응답으로 리디렉션되었다. 성공적으로 확인한 문서라고 인용하지 않는다. 공식 공개자료 README와 실제 버킷/CSV를 1차근거로 삼고, 문서 접근 실패는 별도 보존한다.

실계좌/비밀/지갑/서명/주문/유료자료/거래 서비스/다른봇/하위에이전트 불사용. Binance 공개 archive의 계정집계지표이며 개인 계좌 조회가 아니다.

## 전기간 내부 감사로 이어가기 (성과 미계산 유지)

목록에서는 두 종목 모두 평가1704일의ZIP/CHECKSUM이 있고 고정22표본에 누락4행·일부비율결측이 확인되었다. 표본검사로 정상추정하지 않고 `[2022-01-01,2026-09-01)` BTC/ETH 총3408일파일의 내부를 체크섬대조·정렬/중복/5분누락·컬럼별결측/음수/0으로 감사한다. 관측은 공식 naive `create_time`을 파일명과 맞는 UTC 시각으로 해석하되 실시간 공표시각을 알았다고 하지 않는다. 결측수치를0으로 만들거나 보간하지 않는다.

최대8분 작업창, 4개 병렬다운로드 상한, 일별완료파일을 원자기록하며 제한에 닿으면 정확히 재개한다. 현재22표본 캐시 재사용. 모든오류/미완료일과 해시를 보존한다. 데이터 판정 전 신규신호/수익/전진계좌 계산 없음. 이 문단은 전체내부결과를 보기 전에 고정했다.
