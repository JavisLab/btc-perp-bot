# 가격 구조·무효화·청산의 계좌 검증 (1471)

[대화형 계좌 비교](https://arcadot.com/btc-perp-bot/structure-lab.html)

## 결론

**연구를 이어가지만, 이번에도 실전 채택은 0개다.** 채널 추종의 과거 4개 연도가 모두 플러스라는 진전은 있으나, 수익 규모·거래 표본·통계적 불확실성 때문에 충분한 전략으로 판정하지 않는다. ‘매년 플러스’만 맞추면 끝나는 연구가 아니다.

이번 검사는 24시간 사건들의 합산이 아니라 **한 번에 한 포지션을 보유하는 별도 계좌**다. 이전 24시간 검사 결과는 덮어쓰지 않았다. 아래 두 기간은 이미 알려진 BTC 경로를 사용한 탐색이며, 새 미사용 OOS·실전·Hyperliquid 성과가 아니다. 가상 자본은 각 기간 1,000 USDT, 진입 시 손절+비용 예산 .5%/명목100% 상한이다. 과거 E_SPOT(현물·변동성 위험20%)과 위험 설계가 다르므로 누적 수익만으로 공정한 우열을 주장하지 않는다.

기본5후보의 일평균 수익에 대한 14일 블록2,000회·5비교 보정 구간은 주/최근 모두0을 포함한다. 채널 주구간 구간은 [−.0022340,+.0252363]%/일이다. 7/28일에서도 양의 기대값을 확정하지 못한다. 이것은 과거 연구들을 포함한 전체 선택 편향을 교정한 검사가 아니다.

## 자료 감사와 실행 모형

- 공식 월별5분봉59ZIP+일별보조10ZIP의 SHA256 확인. 2021-10~2026-08 517,248행, 시각 공백·보간0.
- 기존43,104시간과 집계 비교 중7시간 차이. 2023-11-10 15·16UTC는 공식 일별1분·5분과 시간봉이 맞아 일별5분으로 복구. 월별 원본 보존.
- 2022-06-23 19, 2022-07-04 11, 2025-01-29 01·02UTC는 OHLC동일/거래량·체결수 상충이 남는다. 2024-10-28 21UTC는 선행 무거래 봉 때문에 시가가 다르며 첫 유효봉 시가는 시간봉과 일치한다. **누락 시각0이 모든 시장정보의 완전성을 뜻하지 않는다.**
- 복구 후 거래량0 봉36개에서는 체결하지 않음. 이번70계좌의 남은 상충 시간 포지션·체결 노출0. 그 사실이 자료 자체의 오류를 해결하지는 않는다.
- 자료SHA: `027edb1a22e540dfda734b31b23fe59daf63c163e44b927b554a758ab47775e3`.
- 4시간봉 완료5분 후 진입, 미리 무효화된 신호 취소. 손절·목표 동시 도달은 손절 우선. 갭은 불리한 시가. 목표는 목표가만. 추적손절은 완료 정보로만 올린다.
- 편도5bp수수료/1.5bp충격, .001BTC 수량·신규50USDT최소를 고정. 실제 과거 규정·호가·부분체결·정확청산·ADL·세금·운영비 미복원. 소액 연구 조건이지 실자금 운용 승인 범위가 아니다.
- 펀딩은 원본7305기록을 사용하되 시간 경계로 정렬하고 시간봉 마크 시가로 금액을 근사한다. 실제 오라클/원시수ms 체결 선후관계까지 복원한 것은 아니다.
- 5분 종가 DD와 각 봉의 불리한 극단 스트레스 DD를 분리한다. 후자는 실제 봉내 고저 순서를 모르는 보수적 진단이며 청산 전에 안 갔을 극단까지 포함할 수 있다.

## 검증·재현

사전 규칙 `c176e5d` → 실행 모형/자료 처리 `acd6296` → JSON 숫자 직렬화 수정 `1b3e497`. 첫 성과 파일 저장 시 NumPy 정수 직렬화 오류가 발생했으며, 수치 타입만 수정하고 규칙·비용·기간은 변경하지 않았다. 주구간 선택 결과는 빈 목록으로 먼저 저장한 뒤 최근 구간을 계산했다.

- 전체110개 검사 통과(기존98+새12). 동일 봉 손절·목표, 진입봉 손절, 갭, 무거래봉, 진입 전 무효화, 펀딩 부호·경계, 신호 미래 참조, 위험수량 및 회계 검사.
- 원본1시간ZIP에서 신호722개 독립 전수 재열거. 원본펀딩과 전체1661개 거래/보유 중1,166,617개5분봉 경로/원장15,174이벤트 대조. 이 수들은 조건별 중복을 포함한다.
- 별도 Decimal 재고 원장과 59,640일말 자산 및5분DD 대조. 최대 일말 차이 3.18e-12USDT.
- 네트워크 소켓 차단 후70계좌 및74산출물 바이트 재현 일치.

계산 검증은 이 모형의 재현성 증거이지 실제 체결이나 미래 수익의 증거가 아니다. 실거래·계좌조회·지갑·장기 paper·매매 daemon은 실행하지 않았다.

## 다음 연구의 순서

1. **종목 이전:** 규칙을 변경하지 않고 ETH 공식 자료에서5후보를 비교한다. BTC 결과에 맞춘 규칙이 특정 시장에서만 우연히 작동했는지, 드문 기회가 반복되는지 본다. 주문 단위·수수료·시세차이는 분리한다.
2. **정보 추가:** 공개된 실제 미결제약정·펀딩·공격적 체결 변화가 가격만으로 만든 국면보다 추가 정보를 주는지 가설과 제외군을 먼저 고정한다. 합성 자료를 실제 기록으로 대체하지 않는다.
3. **새 기간:** 의미 있는 후보의 규칙을 잠그고 이후 데이터로 확인한다. 동일 과거 차트의 더 높은 수치만 보고 만족을 선언하지 않는다.

연구 재개 일정은 거래 봇 가동과 별개다. 새로운 결과가 생기면 기존 결과와 나란히 남기며, 자동 선정으로 실거래에 연결하지 않는다.
