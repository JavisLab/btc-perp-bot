# 연속 OI 정보의 예측 관문 · 성과 전 고정

사건필터와별도질문:큰2% OI변화만보는규칙이정보를버렸는가? 작은/중기계약변화를연속특징으로쓰면가격·확정펀딩만모형보다향후24h가격의예측오차가낮아지는가? 사후매개변수탐색이아니라동결선형모형한쌍으로검사한다. 기존price-Ridge전략은이미실패했고그결과도아는개발/탐색자료다. 이관문은**계좌성과가아니며**, 통과전거래수익곡선을추가하지않는다.

## 규칙

BTC1h완료종가로매6시간경계T에서특징작성. 기본가격특징8개:log수익4/24/168h,log시간수익표본표준편차24/168h,log(c/EMA168h),이전24h확정펀딩합(원시시각<T),이전24h(high−low)/c. EMA는기존2020가격시작부터재귀계산. 대응label=log(c[T+24h]/c[T]);T+24h가있어야완성라벨. 모델입력은T이하만,학습은label완료후2h purge.

추가OI특징6개:수량log변화4/24/168h와각변화×대응가격log수익. raw+5m관측완료가정+추가60분가용지연. endpoint=T−60m,각정확한룩백두끝포함5분격자모두존재·usable=true일때만. 어느창에라도결측/0이면그관측제외·보간없음. 가격-only도동일샘플/동일가용마스크사용해결측효과를분리한다. OI가시작되는2022는학습용;가격과거경로가이미알려졌으므로2023부터도새OOS라부르지않는다.

각분기첫T에직전365일중source≤fit−26h·완성label표본으로학습,표본500미만이면분기전체미계산/부족표기. 학습표준화(ddof0),상수열std=1,절편포함Ridge alpha10. 두모형P_RIDGE(8개)/OI_RIDGE(14개),다른alpha·모형·lookback검색없음. 예측±.10제한. 분기안모형고정,모든실패분기보존.

평가:2023-01-01~2026-01-01와2026-01-01~2026-09-01;자료종료뒤라벨생성금지,각구간마지막24h는제외해주/최근경계label중첩방지. 기본추가OI가용60m,0/240/1440m민감도모두보고. 원래동결2022~25성과와수익률비교하지않음. 이단계엔실제포지션·수량·펀딩cashflow/청산모형없으며오차차이를USDT수익/alpha로표기하지않음. 후속계좌를하게되면기존1000USDT/.001/min50/5bp+1.5bp/1배상한/실제funding조건과명세를다시고정해야한다.

## 사전 기각 관문

두기간각표본≥500,OI기본MSE<동일표본가격MSE,OI예측과실현수익상관>0,주/최근모두오차개선(MSE_P−MSE_OI)의14일달력블록2000회95%CI하단>0이어야추가정보관문통과.7/28일민감도와가용240m에서기본MSE개선의부호도두기간양수여야한다. 하나라도실패시'연속OI예측가치미입증',좋은지연으로기본교체금지. 여러번본개발자료의모형선택편향을제거하는검정이아님.

독립검산:학습행/라벨시간·실제OI격자·미래교란,sklearn과독립표준화정규방정식해의전예측대조,학습모형고정·raw종가label재계산,소켓차단전산출물바이트일치. 비중·거래비용을누락한계좌성과처럼발표하지않음.
