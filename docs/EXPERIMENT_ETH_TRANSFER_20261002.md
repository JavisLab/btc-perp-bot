# ETH 전이 20261002 · 성과 계산 전 고정 명세

작성: 2026-10-02 UTC. DM1471 지속 연구의 첫 예약 회차. **이번 체크포인트는 규칙 동결·공식 원자료 감사이며 ETH 전략 성과는 아직 계산하지 않는다.**

## 연구 질문과 바꾸지 않는 것

BTC에서 이미 검증한 5개 구조 가설이 ETHUSDT 무기한 선물에서도 나타나는가? BTC의 우수 후보만 고르지 않고 `A_ACCEPT / R_RETEST / F_REJECT / P_RESUME / C_CHANNEL` **모두** 이식한다. [기존 결과 전 명세](EXPERIMENT_1471.md)의 신호·국면·최초 손절·목표·추적·시간청산·동시접촉 손절우선·무거래 체결금지 규칙을 그대로 상속한다. 기간·통과 기준·비용·위험을 성과를 본 뒤 완화하지 않는다.

이것은 Binance USDT 외부가격의 탐색적 시장 전이 연구다. BTC 성과를 이미 보았고, ETH 역사도 1458 페어 연구에서 사용했으며 일반적 가격 경로도 알고 있다. **새로운 미사용 OOS, Hyperliquid 성과, 실전 수익 보장이 아니다.** 자료 감사 중 우연히 관측하는 가격도 숨기지 않는다.

## 후보와 진단 · 결과 전 전부 고정

5후보 × 7조건 × 2기간 = **70개 ETH 계좌**: 기본, 실행비용2배, 추가60분 진입/추적 지연, 손절만 추가5bp, 위험 .25%, 위험1%, 확인봉 공격적 체결방향≥55%. 민감도가 좋아도 기본 후보를 대체하지 않는다. 현금은 0수익 기준선이며 BTC 기존 같은 날짜 결과는 재계산 없이 참고한다. BTC의 E_SPOT/E_LS를 ETH 성과로 표시하거나 별도 ETH 규칙을 추가하지 않는다.

시장 전이와 최소금액 차이를 분리하기 위해 **5후보 × 2기간의 기본 규칙에만 최소금액50 USDT 진단 10개**를 추가 고정한다. 이는 같은 ETH 데이터·.001 ETH 수량단위에서 최소금액20→50의 효과만 비교하며 선정에 사용하지 않는다. BTC와 ETH의 .001 단위가 같은 경제적 규모라는 뜻이 아니다. 내림 전/후 수량·위험·명목, 최소금액 거절 건수를 보존한다. 위험확대나 주문 단위 차이로 늘어난 수익을 새 alpha라고 부르지 않는다.

BTC·ETH 공동증거금 또는 50:50 포트폴리오는 이번 명세 밖이다. 별도 사전명세 없이 합성수익/분산효과를 계산하지 않는다.

## 통과 기준과 불확실성

주 구간 **기본**의 CAGR≥10%, 일별 Sharpe≥.8, 5분 종가 DD≤25%, 양수연도≥3/4, 비용2배 순익>0, 최고분기 제외 복리>0, 담보진단 위반0, 최소100왕복을 **모두** 요구한다. 순위는 기본/비용2배 중 낮은 Calmar, 동점 낮은 회전율. 통과0도 그대로 보존한다. 최근 기본·비용2배 손실/희소 거래는 추가 보류 근거이며 최근만 좋은 탈락 후보 승격 없음. 통과는 새기간 검증 후보일 뿐 실전채택이 아니다.

모든 후보/실패/건너뛰기, 연도·분기·롱숏·국면·보유시간·자산/비용 원장을 공개한다. 일수익 14일 원형블록 2,000회, 7/28일 민감도, 95% 및 ETH 5후보 Bonferroni 구간. 기존 BTC와 같은 고정 난수 정책을 유지하며 서로 독립인 시장 증거라고 주장하지 않는다. 이전 여러 연구의 선택 편향까지 제거하지 못한다.

## 성과에 앞서는 자료 승인 관문

1. ZIP 원본과 공식 CHECKSUM 보존·SHA256 대조. 시각단위·순서·중복·전체범위·정확 봉마감·OHLC·거래량/quote/taker buy·체결수 검증. 1시간 OHLC는 기존 시장 dataset `9909be60d1d4db6b47f766de26894de9cbb55222530f9c3bbdbc19ef0899faa4`와 전수 비교.
2. 5분→1시간 OHLC/거래량/체결수를 전수 비교. 가격·체결수는 정확 비교, 합산 volume/quote/taker 값은 부동소수점 오차 배제를 위한 절대 허용차 .00001. 허용차는 가격/거래 규칙의 조정이 아니다.
3. 차이가 있는 날짜는 공식 일별5분 및1분 원본·체크섬을 모두 대조. 기존 BTC와 같이 **두 일별 원본의 가격과 체결수가 기존 시간봉과 일치하는 가격충돌**만 해당 시간의 일별5분으로 복구. 거래량만 다르면 임의 유리한 버전을 선택하지 않고 월별 유지·상충 보존. 선행 무거래봉의 시가 차이는 별도 분류. 보간0.
4. 해결되지 않은 모든 충돌·자료 완전성 한계를 공개. 무거래5분에는 체결 없음. 성과 계산 시 잔여 충돌 시간의 신호/보유/체결 노출을 별도 검산하고 영향 후보는 증거 한계로 표시한다. 공백0은 경제적 자료 완전성을 보장하지 않는다.
5. 데이터/구현 해시 커밋 후 성과 계산. 독립 원자료·원장 검산, 미래 데이터 교란·지연·롱숏 비용/펀딩·최소량 검사를 거치고 소켓 차단 전체 산출물 재현 후 검증된 결과만 게시한다.
