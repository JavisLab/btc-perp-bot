기존 명세 eaacfbd, 자료 감사 786ca85를 유지한다. `tools/eth_transfer_study.py`는 별도 namespace로 SHA 고정된 BTC 연구엔진을 읽으며 BTC 소스/성과를 변경하지 않는다. 자료 로더와 수량 산정만 ETH 전용이고, 신호/원장/청산/비용은 기존 함수 그대로다. 70계좌 + min50 진단10계좌를 모두 보존한다. 정렬 동률에는 사전명세의 낮은 회전율을 적용한다.

수량은 min(위험한도, 명목한도, 시장최대2000)에서 .001 단위 내림. minQty .001/minNotional20(진단만50)을 충족하지 않으면 거절한다. 모든 산정 시도는 내림 전후 수량/명목/손절위험/거절사유와 시도순서, 실제 진입은 source/time을 남긴다. 거절 시도는 순서만 기록되며 시각이 없는 것을 실제 체결이라고 표시하지 않는다.

## 상충 노출 진단 (선택/대체 성과 계산 아님)

- 자료 감사의 6시간을 그대로 보존한다. 기본 선택은 기존 공식1h 신호·월별5m 체결이다.
- 각 상충시간과 원신호의 확인4h/가격룩백/일말 국면의 보수적 의존 범위를 검사한다. 가격룩백 상한은 A/F 21, R 26, P 40, C 55 이전4h봉; 현재 확인봉을 포함한다. 일말 국면은 당시 알려진20개 일봉 종가다. 이것은 계산에 읽힐 수 있는 범위이며 모든 가격이 실제 min/max를 결정했다는 뜻은 아니다. 거래량/공격적체결 비율은 현재 확인4h봉에만 사용한다.
- 추가로 상충6시간의1h행을 해당월5m집계로 치환한 진단 입력에서 원신호/추적값만 비교한다. 차이는 보존하되 새 계좌 성과를 계산하거나 유리한 자료로 바꾸지 않는다. 부재 신호가 새로 생기는 경우도 비교한다.
- 각 계좌의 보유5m·진입·청산·진입대기구간과 상충6시간 교집합, 실제 진입 신호의 의존성을 계산한다.
- 무거래봉은 대기중 손절취소와 체결을 만들지 않는다. 기존 엔진의 보유 극단값 위험진단은 무거래 가격도 포함하며 이는 거래 가능한 가격/청산가가 아닌 보수적 스트레스다. 영향이 있으면 노출을 밝히고 규칙을 바꾸지 않는다.
- 독립 raw 신호 열거, Decimal 원장/펀딩/일말/5m DD와 실제 전 보유경로를 검산한다. 기존309자료 수집감사를 반복하지 않으며 필요한 신호·펀딩 원자료만 독립검산에 읽는다.
- 단위검사와 검산이 통과한 후 소켓을 차단해 전체 성과 산출물을 별도 경로에 재생성·바이트대조한다. 실제 수익·새 OOS·운영 서비스가 아니다.
