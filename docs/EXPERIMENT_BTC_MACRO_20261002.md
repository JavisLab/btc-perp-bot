# BTC FOMC 이후 금리 재평가 · 성과 전 명세

## 근거와 독립 질문
Q19 Ma/Tian/Hsiao/Deng(2022,10.1016/j.ribaf.2022.101711)의 직접 읽은 초록은 FOMC일 식별된 2년물 금리 충격과 BTC 반대 반응 및 수일 지속을 보고한다. 최종 전문은 아직 미확보다. **일별 DGS2 변화는 논문의 예상외·고빈도 정책충격이 아니다.** 아래는 정책회의에 국한된 일별 금리 재평가가 보수적인 공개 지연 후에도 BTC 방향 정보를 남기는지에 관한 우리 별도 반증 실험이다. 인과효과·논문 재현으로 부르지 않는다. 기존 가격/성과는 탐색자료, 새로운 OOS 아님.

공식 FOMC 달력은 연8회 정례회의와 실제 결정일을 제공하며 의사록은 3주 후다. 의사록 발표를 정책발표로 착각하지 않는다. 공식 2022-03-16 성명은 14:00EDT. Treasury 방법론(2025-02-18 개정)은 약15:30ET 관측/대개18:00ET 공개, 지연 가능; 현재 XML updated는 과거 공개시각을 증명하지 않는다. 대신 ALFRED의 **당시 날짜 빈티지 CSV**를 사용한다. 2022-01-26 빈티지에는 당일 DGS2가 없고 01-27 빈티지에는 1.13이 존재함을 확인했다. 날짜 단위 빈티지는 정확한 분 단위 수신기록이 아님을 유지한다.

## 데이터·가용 경계
정례 FOMC 결정일 2022~2025 각8개, 2026-01~08 5개 =37개. 달력의 2025-08-22 notation vote/예정미래/표본밖 제외. 각 결정일 d에 대해 ALFRED DGS2 **d+1 달력일 빈티지**를 고정, d−7…d 구간만 수집. q = d의금리−직전유효관측금리(연율 percentage-point 단위), q부호만 사용. 전일은 같은 빈티지 안의 엄격히 이전 관측, 최대7일. .01percentage-point=1bp. 오늘 수정된 빈티지/최신Treasury로 결측 대체 금지. 헤더 DGS2_YYYYMMDD, 날짜·중복·유한값 감사, 원시CSV·URL·SHA 보존.

빈티지 d+1의 미국 현지 하루가 모두 끝난 뒤에도 여유를 두어 **d+3일00UTC**에만 새 정보 사용, 기본 체결은 그로부터1h 후. 조기체결/논문 계수의 수익률 곱셈 없음. 그때부터 **5달력일**을 고정 이벤트창으로 한다(한 주 내 정보흡수라는 사전 가설; 1/3/10일 선택 탐색 안함). q누락/가격누락이면 그 이벤트창 공통 cash 및 자료불완전 표시; 원자료 네트워크실패는 수집미완료로 처리하고 누락신호로 둔갑시키지 않는다. 37개 완전성 미달은 승격 불가.
