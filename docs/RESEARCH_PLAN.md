# BTC 검증 환경 v1 — 결과 조회 전 고정한 연구 조건

2026-09-30 DM1428에서 구축 승인. 실제 지갑·자금·서명·계좌조회와 독립한 `btc-research` 실행 경로.
기존 `btc-bot` 주문 기능은 수정하거나 가동하지 않는다.

- BTC 기본 perpetual, 1시간봉, 최근 120일(최대 200일). 공식 캔들 API 최근 5,000개 제한 안에서만 수집.
- 시작 가상자금 1,000 USDC, 진입 목표 명목금액은 평가자산의 50%, 진입 시 최대 1배까지 설정 가능.
- 개발 70% / 뒤쪽 평가 30% 시간순 분리. 모든 전략의 평가 시작 자산·포지션은 동일하게 초기화.
- 추세(20/60 SMA, 0.1% 중립), 돌파(직전24시간), 평균회귀(직전48시간, 진입2σ/청산0.3σ) 고정 세 규칙.
- 개발 구간 순수익만으로 1개 후보를 선택하고 별도 평가 성과를 표시. 파라미터 탐색 없음.
- 비교 기준은 현금과 같은 노출 비중의 BTC **선물** 매수 후 보유. 현물 보유 수익률로 소개하지 않는다.
- 수수료 편도4.5bp, 반스프레드0.5bp, 추가슬리피지1bp. 2배 거래비용 및 한 시간 추가 지연 스트레스도 별도 표시.
- 시간별 실제 과거 펀딩률 사용. 당시 oracle 가격은 이 API에 없으므로 직전 1시간봉 종가로 명목금액 **추정**.
- 종가까지 확정된 봉으로만 판단하고 다음 봉 시가에 가상 체결. 신호 봉의 종가에 소급 체결하지 않는다.
- 전략은 관측 평가자산의 고점 대비20% 하락 시 이후 신규진입 정지/다음 체결 기회에 정리. 설정 손실 한도 보장 아님.
- 백테스트는 호가 깊이·정확한 청산·봉내 경로를 복원하지 않는다. 종가 기준 낙폭이며 체결 비용 추정치를 명시.
- 실시간 paper는 같은 전략/회계를 사용하고 관측 주문장 깊이·가상 IOC 가격제한에 따라 부분/미체결 가능.
- paper 계좌는 재시작 시 잔고·포지션·누적비용·처리시간을 보존. 중단 구간의 가상 주문을 과거가격으로 만들지 않는다.
- 결과가 손실이어도 그대로 보고. 평가 구간 결과를 보고 다시 고치면 그 구간은 더 이상 미사용 평가가 아님.

목표 산출물: 검증된 원자료/해시, JSON·CSV·독립 HTML 보고서, 재개 가능한 paper 계좌, 재현 명령과 한계 문서.
수익성 입증·실거래 체결 보증이나 자동 실거래 전환은 이 환경의 산출물이 아니다.
