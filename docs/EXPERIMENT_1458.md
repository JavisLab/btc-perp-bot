# 전략군 비교 연구 — 사전 명세 1458

고정일: 2026-10-01. 이 파일은 새 후보의 성과 계산 **전에** 커밋한다.
목적은 연구 후보 선정이며 실거래·자동 상시 모의운영 승인이 아니다.

## 왜 다시 조사하는가

기존 T1은 2022~2025 **4년** 누적 6.99%, 연복리 1.70%였고 채택 기준에 실패했다.
이번에는 단일 이동기간을 고치는 대신 수익원이 다른 전략군을 검토한다.
최신 논문이라는 이유만으로 성과를 신뢰하지 않는다. 문헌의 결과와 우리 재현 결과를 분리한다.

## 데이터와 관측 경계

- BTC 기존 공식 Binance 현물/선물/마크/펀딩(2020~2026.5)을 보존한다. ETH 선물/마크/펀딩을 공식 아카이브에서 추가한다.
- 2026년 6~9월 월별 원자료를 확인하되, 두 자산의 선물/마크/펀딩이 모두 완성된 마지막 월까지만 최근 비교에 쓴다. 부족한 월을 성과에 따라 택하지 않는다. 일별 보충은 원본 체크섬 확인 후 실제 누락 행만 반영한다.
- 2022~2025는 이미 본 **탐색/비교 구간**. 2026도 가격 경로에 대한 사전 지식과 기존 HL 관측이 있으므로 완전한 미사용 OOS가 아니다. 규칙을 이번에 고정해도 이 사실은 달라지지 않는다.
- ML/페어의 각 학습·추정 창에는 그 시점 이전 자료만 넣는다. 이는 계산상 워크포워드이며 연구자 수준의 새로운 전진 검증을 뜻하지 않는다.
- 초기 2020~2021은 준비/학습. 주 비교는 2022-01-01~2026-01-01, 최근 비교는 2026-01-01~최종 공동 월말. 각 구간 1,000 USDT 별도 계좌, 구간 안 분기·연도 경계에서 재설정하지 않는다.
- ETH는 현재 살아남은 두 대형 자산을 고른 제한적 사례이다. 전체 코인 페어·횡단면 전략의 생존편향 없는 증거로 확대하지 않는다.

## 공통 조건

- 방향성 전략 연 변동성 목표 20%, 최근 완료 일봉 20개 로그수익률의 표본 표준편차×√365. 조정 시 명목 최대 자산 100%, 현물 차입 없음. 이 위험 예산은 **연구 비교용**이며 사용자 실자금 위험 허용치가 아니다.
- 같은 위험 규칙의 현물/선물 상시 롱, 현물 100% 최초 매수보유, 현금, 기존 T1 10%/50% 조건과 T1 20%/100% 조건을 비교한다. 위험 예산 변경의 효과와 신호 변경의 효과를 구분한다.
- 기본 편도: 선물 수수료 5bp, 현물 10bp, 추가 반스프레드+슬립 1.5bp. 현재 고정 규칙: BTC 선물 .001 BTC/min50, ETH 선물 .001 ETH/min20, BTC 현물 .00001 BTC/min5. 과거별 규칙 복원이 아니며 메타 확인 결과가 다르면 결과 계산 전에 부록으로 수정한다.
- 기본 완료 일봉 신호는 다음 UTC 01:00 실제 시간봉 시가에 불리한 비용을 적용한다. ML은 완료된 6시간 경계에서 결정, 1시간 뒤 시가. 미래 가격·당일 미완료 일봉·미래 확정 펀딩률 사용 금지.
- 동일 방향 목표 차이 5%p 미만은 조정 생략, 반전/완전 청산은 밴드 예외. 최소 주문·수량 단위, 종료 청산 비용, 실제 펀딩률을 반영한다. 펀딩 금액은 해당 시간 마크 시가 대용값으로 정산한다.
- 현물 없는 시간에는 체결하지 않는다. 마지막 관측 가격은 평가 표시용으로만 유지하고 누락 시간을 표시한다. 다리 하나가 없으면 페어/캐리 조정 전체를 건너뛴다. 양쪽 동시체결은 가정이며 부분체결·원자성 증거가 아니다.
- 현물은 선물 담보에 포함하지 않는다. 선물 담보는 남은 현금+선물 손익, 담보비율 5% 미만의 보수적 진단을 기록한다. 실제 청산 가격·ADL·호가·봉내 경로·세금·운영비는 복원하지 않는다.

## 비교·선정 절차

1. 후보 **9개 모두** 주 구간 기본·비용2배·추가1시간·추가24시간 지연을 계산. 지연은 원래 신호 목표를 이동하며 미래 신호로 재평가하지 않는다.
2. 사전 연구 스크리닝: 주 구간 CAGR≥10%, Sharpe≥.8, 관측 최대낙폭≤25%, 4년 중 3년 이상 양수, 비용2배 총손익 양수, 최고분기 제외 복리 양수, 담보 진단 위반0. 이 수치들은 수익 보장/실자금 승인 기준이 아니다.
3. 통과 후보를 **기본·비용2배 중 더 낮은 Calmar(CAGR/최대낙폭)** 순서로 정렬. 동점은 낮은 회전율, 그다음 단순한 규칙. 없으면 없음으로 고정. 순위를 최근 구간 결과를 보고 바꾸지 않는다.
4. 순위 고정 후 최근 구간을 모든 후보에 공개. 2026 손실·스트레스 붕괴·특정 연도 의존 여부를 추가 기각 근거로 쓴다. 최근 구간이 좋다고 탈락 후보를 사후 승격하지 않는다.
5. 주/최근 구간 14일 블록 2,000회 부트스트랩으로 평균 및 위험조절 현물 보유와의 Sharpe 차이 95% 구간, 9후보 다중비교 보정 구간을 표시. 7/28일 블록 민감도. 이미 본 자료의 연구 선택 편향까지 제거했다는 주장은 금지.
6. 모든 후보 위험목표 10%와30%는 민감도이며 새로운 후보로 뽑지 않는다(캐리 고정명목은 그대로, 페어도 cap 유지). 결과 후 기간/필터 변경 없음. 추가 연구가 필요하면 별도 명세/버전으로 기록.
7. 통과·새 전진 검증이 없으면 '실전 사용 가능 전략'으로 발표하지 않는다. 대신 연구 우선 후보/탈락/데이터 부족을 구분한다.

문헌 비교에는 횡단면 모멘텀, 초단기 반전, 거래소 간 캐리, 옵션 보험료, ETF/온체인·뉴스, 주문장 마켓메이킹/그리드, LLM/RL, HLP도 포함한다. 데이터·비용 조건이 맞지 않으면 그럴듯한 OHLC 수익곡선을 만들지 않고 정량실험 대상에서 제외한다.
