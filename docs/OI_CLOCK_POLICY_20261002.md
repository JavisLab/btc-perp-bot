# OI 관측시각 검증 · 계좌성과 계산 전

2026-09-30 BTC/ETH 공개 metrics와 OI API의 같은시각 값은 288개 모두 달랐다. ±60분의5분격자 진단에서는 **archive create_time = API timestamp −5분**일 때 종목별 겹치는287개 OI수량이 전부 정확히 일치했다. 이는 사후 발견한 자료시각 가설이지 전략 최적화나 OOS 성과가 아니다. 원본시각은 아직 바꾸지 않았다.

## 고정 확인 단계

- 이 가설을 확인할 날짜는 2026-09-10, 2026-09-20 두 날짜, BTC/ETH 모두. 새 가격수익/계좌/후보 선택 없음.
- 공식 일별 metrics/CHECKSUM과 인증없는 openInterestHist를 다시 받아 수량·금액을 Decimal로 대조한다. CSV 각 `create_time`에 대해 API `timestamp = create_time +300000`를 사전 고정한다. 전체288행을 비교하도록 API 시작/끝을 +5분 맞추며 원시 응답과해시를 보존한다.
- 날짜별 전행 일치가 확인되면 후속 OI 자료 어댑터는 **보수적으로 create_time+5분 이후에만 관측완료 취급**한다. 데이터수집/공표지연은 별도이고 실제 과거최초가용시각을 증명한 것은 아니다. 실전용·새OOS라고 부르지 않는다.
- 불일치하면 추가 이동을 찾아서 통과시키지 말고 상충으로 남겨 차기원인조사를 한다. 현재평가기간까지 같은시각의미라고 입증한 것은 아니므로 가정/민감도를 새성과전명세에 드러내야 한다.
- taker API/공식5m 수량도 작은 차이가 남았다. OI의 +5분 규칙을 모든컬럼에 일반화하거나 기존검증1h taker buy를 이비율로 바꾸지 않는다. 기존펀딩자료 재사용.

## 후속 정규화 경계

날짜 내 시간순이 아닌 파일(BTC107일/ETH111일)은 별도 입력에서 명시적으로 정렬하되 원본을 보존한다. 각종목133개 누락시각은 보간/앞채움하지 않는다. OI수량 또는OI금액이0/결측/음수면 미확인 관측으로 마스크하고,0이 실제무포지션이라는 주장은 하지 않는다. 원본의0과비율결측을 지우지 않는다. 자료어댑터·신호/룩백·추가관측지연/수량·대조군을 새성과 전에 커밋해야 한다.
